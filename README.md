# Land the Plane

A little browser flight game. You start a few miles from Portland International at 3,000 feet over real satellite imagery and 3D terrain, and your job is to get the plane onto a runway in one piece.

On desktop, the arrow keys fly the plane, C and V set the power, and F lowers the flaps. On a phone, drag anywhere to fly and use the buttons at the bottom for power and flaps. Touch down gently and roll out to get your grade.

To run it locally, copy `.env.example` to `.env.local`, add a Mapbox public token, then run `npm install` and `npm run dev`. Pushing to `main` deploys it to [aley.me/land-the-plane](https://aley.me/land-the-plane/) with GitHub Pages.
